# Baset | Personal Portfolio & Tech Directory

A minimalist, high-performance personal portfolio and tech directory for **Baset**, inspired by **yazdan.me** and **Pytopia**.

## Features

- **Zero-Database Jamstack**: 100% static, blazingly fast, hosted for free on Vercel.
- **Bilingual (FA / EN)**: Full Persian & English support with true RTL/LTR switching.
- **Classic Numbered Pagination**: 12 items per page with smooth navigation.
- **Dual Calendar Dates**: Displays both Solar Hijri (شمسی) and Gregorian (میلادی) side-by-side.
- **Dynamic Multi-Color Cards**: Distinct palettes for Telegram bots, Accounting engines, Web development, AI workflows, and Security.
- **Dark & Light Modes**: Pitch-black dark default with eye-friendly light mode.
- **Instant Search**: Client-side filtering by title, summary, and tags.

## Deployment

Deployable to [Vercel](https://vercel.com) with zero configuration.
